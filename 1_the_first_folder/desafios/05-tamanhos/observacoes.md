# Minhas observações
comparacao e acompanhamento dos bits e bytes
## Previsão antes de executar
Tudo de acordo com o PDF
## Resultados dos casos
char:         1 byte
int:          4 bytes
float:        4 bytes
double:       8 bytes
long double:  16 bytes
CHAR_BIT:     8 bits por byte
INT_MIN:      -2147483648
INT_MAX:      2147483647
## O que aprendi e dúvidas

sizeof informa os tamanhos em bytes e CHAR_BIT informa quantos bits há em cada byte. Como CHAR_BIT vale 8, um int de 4 bytes ocupa 32 bits.
