# Ficha com tipos

Base: Aula 2, slides 8–18.

## Desafio

Declare idade como int com 20, nota como double com 8.5 e turma como char com A. Imprima cada uma com um rótulo. Acrescente 1 à idade e imprima novamente.

## Critério de conclusão e casos

Valores exibidos: 20, 8.50, A e 21, nessa ordem. Depois teste idade inicial 0: o valor final deve ser 1.

<details>
<summary>Pista, se precisar</summary>

Use aspas simples no caractere e %.2f para a nota.
