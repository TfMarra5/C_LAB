# Minutos em horas

Base: Aula 2, slides 21–22.

## Desafio

Declare total_minutos como int entre 0 e 10000. Calcule horas completas e minutos restantes e imprima como 2 h 15 min, por exemplo.

## Critério de conclusão e casos

135: 2 h 15 min. 60: 1 h 0 min. 59: 0 h 59 min. 0: 0 h 0 min.

<details>
<summary>Pista, se precisar</summary>

Use divisão inteira e resto por 60.

</details>
