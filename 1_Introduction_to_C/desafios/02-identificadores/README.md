# Nomes de variáveis

Base: Aula 2, slides 3–7.

## Desafio

Classifique em resposta.md: idade, 2nota, nota_final, int, Int, aluno1 e valor-total. Explique cada decisão. Explique também se nota e Nota são o mesmo nome. Reescreva os nomes inválidos.

## Critério de conclusão e casos

Justifique pela posição dos dígitos, palavras reservadas, caracteres e distinção entre maiúsculas e minúsculas.

<summary>Pista, se precisar</summary>

Int não é a palavra-chave int. Para seus próprios nomes, prefira letras ASCII, dígitos e underscore sem começar por dígito ou underscore.
