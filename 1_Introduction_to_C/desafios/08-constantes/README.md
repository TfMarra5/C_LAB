# Conversor de temperatura

Base: Aula 2, slides 19–22 e 26.

## Desafio

Declare celsius como double e use constantes para o fator 9.0/5.0 e o deslocamento 32.0. Calcule Fahrenheit e imprima com duas casas.

## Critério de conclusão e casos

0: 32.00. 100: 212.00. -40: -40.00.
