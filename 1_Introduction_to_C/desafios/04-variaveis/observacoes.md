## Previsão antes de executar

## Resultados dos casos
impressão no terminal certinho das informações todas.
## O que aprendi e dúvidas
char = %c

| Símbolo | Função | Exemplo |
|---|---|---|
| `%c` | Imprime um caractere (`char`) | `'C'` |
| `%s` | Imprime uma string | `"DE0917"` |
| `%d` | Imprime um inteiro (`int`) | `20` |
| `%f` | Imprime um número decimal | `8.500000` |
| `%.2f` | Imprime com duas casas decimais | `8.50` |
| `\n` | Faz uma quebra de linha | Move a próxima saída para outra linha |
