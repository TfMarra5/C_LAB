# Rastrear atualizações

Base: Aula 2, slides 22–23.

## Desafio

Comece com int a=5; faça int b=a++; e imprima a e b. Em seguida, reinicie a com 5; faça b=++a; e imprima ambos. Por fim, aplique a+=3 e a*=2 em instruções separadas e imprima a.

## Critério de conclusão e casos

Primeiro par: a=6, b=5. Segundo par: a=6, b=6. Valor final de a: 18.

<details>
<summary>Pista, se precisar</summary>

Faça cada alteração em uma instrução própria, fora do printf.
