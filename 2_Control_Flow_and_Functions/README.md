# 2_Control_Flow_and_Functions

Etapa baseada na apresentação **Control flow, functions**. Contém os desafios 13–24 sobre decisões, `switch`, `scanf`, laços, `break`, `continue`, funções, protótipos e escopo.

Leia [o guia desta etapa](docs-etapa-3.md) e faça os desafios em ordem. Cada pasta traz seu próprio enunciado e `main.c`. O projeto 03 reúne leitura validada de notas e funções.

Para compilar um exercício com GCC no terminal: `gcc -std=c11 -Wall -Wextra -Wpedantic desafios/13-par-ou-impar/main.c -o programa.exe`.
