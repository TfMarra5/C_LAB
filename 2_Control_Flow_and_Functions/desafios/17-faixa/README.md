# Adivinhar o número

Base: Aula 3, slides 14–16 e 32–33.

## Desafio

Defina const int segredo no código e leia um palpite. Diga se acertou, se o segredo é maior ou se é menor. Trate entrada inválida. Não é necessário repetir palpites ainda.

## Critério de conclusão e casos

Segredo 7: palpites 7, 4 e 10 produzem acertou, segredo maior e segredo menor.
