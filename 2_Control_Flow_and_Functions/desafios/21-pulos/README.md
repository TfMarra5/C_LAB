# Múltiplos sem um valor

Base: Aula 3, slides 23–26.

## Desafio

Leia N e use for de 1 até N. Pule múltiplos de 3 com continue; encerre com break quando chegar a 20. Imprima cada valor em uma linha.

## Critério de conclusão e casos

N=10: 1, 2, 4, 5, 7, 8, 10. N=25: imprima os mesmos valores permitidos até 19; não imprima 20 nem valores seguintes.

<summary>Pista, se precisar</summary>

Decida a ordem entre break e continue. Faça o teste do limite antes de imprimir.
