# Classificar um número

Base: Aula 3, slides 5–8.

## Desafio

Leia um int e imprima positivo, negativo ou zero usando if / else if / else. Verifique o retorno do scanf.

## Critério de conclusão e casos

Entradas 12, -3 e 0 cobrem as três mensagens.

<details>
<summary>Pista, se precisar</summary>

As condições podem ser numero > 0 e numero < 0; o caso restante é zero.
