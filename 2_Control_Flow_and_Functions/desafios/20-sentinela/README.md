# Média até zero

Base: Aula 3, slides 21–22 e 32–33.

## Desafio

Leia inteiros um por vez. Zero encerra a entrada e não participa da média. Use do...while para pedir ao menos uma entrada. Conte os valores não zero; no final, imprima a média como double. Trate falha de leitura e o caso em que a primeira entrada é zero.

## Critério de conclusão e casos

Entradas 4, 6, 0: média 5.00. Apenas 0: informe que não há valores para calcular média.
