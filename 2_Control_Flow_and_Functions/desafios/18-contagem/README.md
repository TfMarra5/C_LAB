# Contar até N

Base: Aula 3, slides 14–16.

## Desafio

Leia N e use for para imprimir os inteiros de 1 até N, um por linha. Para N <= 0, informe que N deve ser positivo.

## Critério de conclusão e casos

N=1: 1. N=4: 1, 2, 3, 4. N=0: mensagem e nenhum número.
