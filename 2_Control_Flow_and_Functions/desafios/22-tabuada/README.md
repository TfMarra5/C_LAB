# Tabuada

Base: Aula 3, slides 14–19.

## Desafio

Leia um inteiro e imprima sua tabuada de 1 a 10 usando for. Valide a leitura.

## Critério de conclusão e casos

Para 3: linhas de 3 x 1 = 3 até 3 x 10 = 30. Teste também 0 e -2.

<details>
<summary>Pista, se precisar</summary>

Use uma variável contadora de 1 a 10 e formate cada linha com printf.
