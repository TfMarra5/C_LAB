# Maior de três valores

Base: Aula 3, slides 4–11.

## Desafio

Leia três int e encontre o maior usando decisões. Trate falha de leitura. Valores iguais também devem funcionar.

## Critério de conclusão e casos

4, 9, 2: 9. -1, -1, -5: -1. 6, 2, 6: 6.

<details>
<summary>Pista, se precisar</summary>

Mantenha uma variável maior e atualize-a quando encontrar um valor maior.
