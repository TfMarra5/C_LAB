# Par ou ímpar

Base: Aula 3, slides 4–8.

## Desafio

Leia um int e diga se é par ou ímpar. Primeiro verifique se scanf leu um inteiro.

## Critério de conclusão e casos

Entradas -4, 0 e 7: par, par e ímpar. Entrada de letra: mensagem de entrada inválida.

<details>
<summary>Pista, se precisar</summary>

Use scanf("%d", &numero), teste se o retorno foi 1, e só então use numero % 2.

</details>
