# Funções de cálculo

Base: Aula 3, slides 34–37.

## Desafio

Declare protótipos e implemente: int somar(int a, int b), int quadrado(int n) e double converter_para_fahrenheit(double celsius). Chame as funções de main e imprima os resultados. Não use variáveis globais.

## Critério de conclusão e casos

somar(3,4)=7; quadrado(-3)=9; converter_para_fahrenheit(0)=32.00 e converter_para_fahrenheit(100)=212.00.

<summary>Pista, se precisar</summary>

Coloque os protótipos antes de main e as definições depois. Cada chamada recebe argumentos e devolve um valor.
