# Somar de 1 até N

Base: Aula 3, slides 18–22.

## Desafio

Leia N positivo e calcule 1+2+...+N usando while. Imprima a soma. Trate entrada inválida e N não positivo.

## Critério de conclusão e casos

N=1: 1. N=4: 10. N=10: 55.

<details>
<summary>Pista, se precisar</summary>

Inicialize contador e soma antes do laço. Atualize ambos dentro do while.

</details>
